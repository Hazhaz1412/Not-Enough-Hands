# Totem ritual models

All four files are Kenney's, released under **CC0 1.0** (public domain, no
attribution required). Kept here with their original filenames so they can be
traced back to the pack they came from.

- `statue_head.glb` — carried by `items/totem.tscn` as the totem itself.
- `statue_obelisk.glb` — unused spare, kept as a second totem silhouette.
  Both from **Nature Kit** (v1.0): https://kenney.nl/assets/nature-kit
- `campfire-pit.glb` — the brazier body in `items/totem_brazier.tscn`.
- `resource-wood.glb` — the firewood in `items/firewood.tscn`.
  Both from **Survival Kit** (v2.0): https://kenney.nl/assets/survival-kit

The flame, the glow light and the "seen by the camera" highlight are all added
in the scenes/scripts; the source models carry no lights or emissive materials.
